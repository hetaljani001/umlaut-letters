# Umlaut Letters

A free one-page web tool for copying, pasting, and typing German umlaut letters: **Ä Ö Ü ä ö ü ß**.

**Use it here: https://umlautletters.com**

## What it does
- Click-to-copy Ä, Ö, Ü, ä, ö, ü, and ß
- Keyboard shortcuts for Windows (Alt codes), Mac (Option key), and mobile (long-press)
- Unicode, Alt, and HTML code reference (`&auml;` `&ouml;` `&uuml;` `&szlig;`)

## Quick shortcuts
| Character | Windows | Mac | HTML |
|---|---|---|---|
| ä | Alt + 0228 | Option+U, then A | `&auml;` |
| ö | Alt + 0246 | Option+U, then O | `&ouml;` |
| ü | Alt + 0252 | Option+U, then U | `&uuml;` |
| Ä | Alt + 0196 | Option+U, then Shift+A | `&Auml;` |
| Ö | Alt + 0214 | Option+U, then Shift+O | `&Ouml;` |
| Ü | Alt + 0220 | Option+U, then Shift+U | `&Uuml;` |
| ß | Alt + 0223 | Option + S | `&szlig;` |
